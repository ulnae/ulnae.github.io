# 鱼线总览

> 本文档为鱼线知识体系入口文件，汇总介绍市面上所有主流鱼线的材质类型、核心参数概念，并提供按垂钓方式分类的详细文档导航。


## 一、鱼线材质分类总表

### 1. 尼龙线（Nylon Monofilament）

| 项目 | 说明 |
|------|------|
| **材质** | 聚酰胺纤维（尼龙6、尼龙66），单丝挤出成型 |
| **特点** | 延展性好、柔软、价格低廉、结节强度较高、有弹性可缓冲冲击力 |
| **拉力范围** | 1号 ≈ 4lb（约1.8kg），5号 ≈ 20lb（约9kg），10号 ≈ 40lb（约18kg） |
| **比重** | 约 1.14，略重于淡水，沉水速度适中 |
| **折射率** | 约 1.53，水中可见度中等 |
| **耐磨性** | 一般，礁石/结构区容易磨损 |
| **吸水性** | 长期浸泡吸水率约8\%~10%，吸水后强度下降约10\%~15% |
| **主要用途** | 台钓主线/子线、淡水手竿钓、筏钓、矶钓（浮水型）、路亚钓（部分场景）、前导线 |
| **细分类型** | 普通尼龙线、浮水尼龙线（矶钓专用）、高感度尼龙线、软调子线、硬调主线 |

### 2. 碳氟线（Fluorocarbon, FC）

| 项目 | 说明 |
|------|------|
| **材质** | 聚偏二氟乙烯（PVDF），单丝挤出成型 |
| **特点** | 耐磨性极强、折射率接近水（1.42 vs 水1.33）几乎隐形、无吸水性、感度好、抗UV |
| **拉力范围** | 1号 ≈ 4lb（约1.8kg），5号 ≈ 22lb（约10kg），10号 ≈ 45lb（约20kg） |
| **比重** | 约 1.78，沉水快 |
| **折射率** | 约 1.42，水中近乎隐形 |
| **耐磨性** | 极佳，是目前商业鱼线中耐磨性最好的材质之一 |
| **吸水性** | 几乎为0，长期浸泡强度不下降 |
| **主要用途** | 路亚前导线、海钓子线、矶钓子线、咬铅线、防咬线 |
| **细分类型** | 纯碳氟线（100% FC）、碳氟涂层尼龙线（FC Coated）、硬调碳氟、软调碳氟 |

### 3. PE编织线（Braided PE Line）

| 项目 | 说明 |
|------|------|
| **材质** | 超高分子量聚乙烯纤维（UHMWPE），多股编织而成 |
| **特点** | 拉力极高（同线径下拉力是尼龙线的3~5倍）、零延展（感度极佳）、无记忆性、不吸水 |
| **拉力范围** | 0.4号 ≈ 8lb（约3.6kg），1.0号 ≈ 15lb（约6.8kg），3.0号 ≈ 40lb（约18kg），5.0号 ≈ 65lb（约29kg） |
| **比重** | 约 0.97，浮水 |
| **耐磨性** | 较差（纯PE耐磨性不如碳氟），需搭配前导线使用 |
| **编数体系** | 4编、8编、12编、16编等（详见材质与编数专题文档） |
| **主要用途** | 路亚主线、海钓主线、雷强钓、远投钓、船钓 |
| **细分类型** | 4编（经济型）、8编（主流型）、12编（高密度）、16编（超圆滑）、X编涂层线 |

### 4. 钢丝线（Wire Line / Leader）

| 项目 | 说明 |
|------|------|
| **材质** | 不锈钢丝、钛合金丝、多股合编钢丝 |
| **特点** | 防咬断能力极强、不可拉伸、抗腐蚀 |
| **拉力范围** | 20lb~300lb+ |
| **主要用途** | 海钓前导线（防牙鱼：鲅鱼、鲨鱼、GT等）、拖钓前导线 |
| **细分类型** | 单股钢丝、七股合编钢丝、钛合金记忆丝 |

### 5. 飞蝇线（Fly Line）

| 项目 | 说明 |
|------|------|
| **材质** | 外层PVC/聚氨酯涂层 + 内芯编织芯线 |
| **特点** | 重量集中在线体本身（用于抛投）、锥度设计（重量前置等）、浮水/沉水特性 |
| **主要用途** | 飞钓专用 |
| **细分类型** | 重量前置（WF）、双锥度（DT）、浮水线（F）、沉水线（S/S1/S2/S3...）、全沉线、浮水尖端沉水线 |

### 6. 大力马线（Dyneema）

| 项目 | 说明 |
|------|------|
| **材质** | 超高分子量聚乙烯纤维（UHMWPE），与PE线同类材质 |
| **特点** | 与PE编织线类似，大力马为品牌名（荷兰DSM公司），现已成通用称呼 |
| **主要用途** | 多用于前导线/连接环（大力马前导）、部分场景作主线 |

### 7. 碳线/碳素线（Carbon Coated / 碳氟涂层线）

| 项目 | 说明 |
|------|------|
| **材质** | 尼龙芯 + 碳氟涂层 |
| **特点** | 介于尼龙线和碳氟线之间的性能，价格较纯碳氟便宜 |
| **主要用途** | 台钓子线、淡水路亚前导、经济型前导线 |

### 8. 复合线 / 熔合线（Fused Line）

| 项目 | 说明 |
|------|------|
| **材质** | PE纤维 + 树脂熔合涂层（如FireLine火线） |
| **特点** | 结合PE的高拉力和涂层后的耐磨/圆滑性，线体更圆滑利于抛投 |
| **主要用途** | 路亚主线（尤其中轻型路亚） |


## 二、核心参数概念

### 1. 编数（Strands）

PE编织线由多股纤维编织而成，编数代表编织所用股数：

| 编数 | 特点 | 适用场景 |
|------|------|----------|
| **4编** | 结构松散、表面粗糙、耐磨稍差但便宜 | 经济型路亚、船钓底钓 |
| **6编** | 介于4编和8编之间，性价比型 | 通用路亚 |
| **8编** | 表面圆滑、抛投远、感度好、主流选择 | 精细路亚、远投路亚 |
| **12编** | 更圆滑、更密实、线径更细 | 远投竞赛、精细作钓 |
| **16编** | 极致圆滑、线径极细、手感极佳 | 高端远投、竞技路亚 |

> 编数越高，线体越圆滑、越细、抛投越远、手感越好，但价格也越高。编数不是越高越好，4编线在耐磨和打结方面有时反而更有优势。

### 2. 号数（Line Rating / 号）

亚洲常用号数制（日本标准JIS），1号 ≈ 4磅（约1.8kg拉力）：

| 号数 | 磅值(lb) | 公斤拉力(kg) | PE线径参考(mm) | 尼龙线径参考(mm) |
|------|----------|-------------|----------------|------------------|
| 0.3号 | 1.2lb | 0.55 | 0.05 | 0.09 |
| 0.6号 | 2.5lb | 1.1 | 0.07 | 0.12 |
| 0.8号 | 3lb | 1.4 | 0.08 | 0.14 |
| 1.0号 | 4lb | 1.8 | 0.10 | 0.16 |
| 1.5号 | 6lb | 2.7 | 0.13 | 0.20 |
| 2.0号 | 8lb | 3.6 | 0.16 | 0.23 |
| 3.0号 | 12lb | 5.4 | 0.20 | 0.28 |
| 4.0号 | 16lb | 7.3 | 0.25 | 0.33 |
| 5.0号 | 20lb | 9.1 | 0.30 | 0.37 |
| 8.0号 | 32lb | 14.5 | 0.40 | 0.47 |
| 10号 | 40lb | 18.1 | 0.50 | 0.52 |

> 注意：PE线的号数和实际线径与尼龙线差异很大。同样1号，PE线径约0.10mm但拉力远超尼龙1号。部分品牌PE线存在"虚标"现象（标称号数小于实际线径）。

### 3. 磅值（Pound Test, lb）

欧美常用的拉力标注方式，1lb ≈ 0.4536kg。

### 4. 线径（mm）

实际物理直径。需要注意：
- 尼龙线和碳氟线的线径与号数关系较统一
- PE线因编织结构不同，同号数不同品牌的线径差异较大

### 5. 结节强度（Knot Strength）

鱼线打结后的拉力保留率。一般：
- 尼龙线：打结后保留60\%~75%原线拉力
- 碳氟线：打结后保留50\%~65%原线拉力
- PE线：打结后保留40\%~60%原线拉力（需用专用结如PR结、FG结）

### 6. 延展率（Stretch / Elongation）

| 材质 | 延展率 | 特点 |
|------|--------|------|
| 尼龙线 | 15\%~30% | 弹性大，可缓冲冲击，但感度低 |
| 碳氟线 | 5\%~15% | 延展小，感度较好 |
| PE编织线 | 3\%~5% | 几乎无延展，感度极佳 |
| 钢丝线 | <1% | 无延展 |

## 六、使用与保养建议

### 1. 日常使用

- **PE线**：避免直接接触礁石/贝壳等锋利结构，必须搭配前导线使用；定期检查线体是否有起毛/磨损
- **尼龙线**：注意生产日期，尼龙线有老化期（一般2~3年），开封后建议1年内用完；避免阳光直射存放
- **碳氟线**：存放于阴凉干燥处，避免高温（碳氟线高温下会变形）；打结时注意湿润线体避免摩擦发热
- **飞蝇线**：使用后用淡水清洗，避免盐水腐蚀涂层；存放时松弛卷绕，避免记忆变形

### 2. 线轮保养

- 每次出钓后用淡水冲洗线轮和线体表面
- 海钓后必须彻底冲洗，盐水会加速PE线老化和线轮腐蚀
- PE线建议每年更换一次（频繁使用则半年更换）
- 尼龙线建议每季检查，有发黄/变脆则更换

### 3. 打结注意事项

- PE线必须使用专用打结方法（PR结、FG结、 Alberto结）连接前导
- 碳氟线打结前务必湿润线体，减少摩擦发热导致的强度损失
- 尼龙线使用常规结即可（改良半血结、帕洛玛结等）
