# 传统钓浮漂详解

> **使用场景**：长竿短线、草洞递饵、走水野河等中国传统钓法场景，结构简单、皮实耐用。
> **适用人群**：传统钓爱好者、野钓玩家、草洞钓鲫玩家、预算有限的入门者。

## 1. 七星漂（蜈蚣漂）

### 基本信息

| 项目 | 内容 |
|------|------|
| **类型** | 线浮漂（多体漂）——传统钓代表 |
| **形状/结构** | 5~12 粒漂豆（鹅毛梗、塑料珠、桐木/泡沫粒）串于主线上，间距 1~3cm；配合朝天钩活坠使用 |
| **常见材质** | 鹅/鸭羽毛梗、塑料、桐木、泡沫 |
| **常见规格** | 漂豆 5~12 粒，单粒直径 3~8mm |
| **对象鱼种** | 鲫鱼（草洞神钓）、鲤鱼、黄颡鱼 |
| **常见品牌** | 手工自制、汉鼎、光威、各类渔具店散装 |
| **普遍价位** | 5~50 元（自制几乎零成本） |

### 优缺点

**优点：**
- 无需精细调漂，水线上下移动即可适应水深变化，草洞障碍区「递饵」精准
- 信号直观：送漂（上浮）即鲫鱼咬钩经典漂相，新手秒懂
- 水线短、线组贴身，风线少，抗风干扰
- 成本极低，挂草损失不心疼
- 冬季长竿短线钓草洞的效果至今无可替代

**缺点：**
- 不适合深水远投（漂豆串长距离观漂吃力）
- 风浪大时漂豆随波起伏，难以分辨鱼讯
- 无法像立漂一样呈现丰富调钓状态（灵敏与迟钝调节粗放）
- 抛投方式受限，多为「递」「荡」，效率低于台钓

### 搭配建议

| 搭配项目 | 建议 |
|---------|------|
| **鱼线** | 传统钓主线 0.8~1.5 号（线上直接穿豆） |
| **鱼竿** | 传统长竿 8~12m（伸缩炮竿），或 5.4~7.2m 手竿 |
| **最佳组合** | 10m 炮竿 + 七星漂 + 朝天钩 + 红虫蚯蚓（冬季草洞钓大鲫鱼标配） |

### 选购建议

- **入门**：直接买成品七星漂线组（10~20 元），省去自制麻烦
- **进阶**：鹅毛梗手工漂豆信号更柔和自然，传统钓老炮标配
- **钓深水**：选用大粒泡沫漂豆（浮力大、配坠重），下沉定位快
- 漂豆数量并非固定 7 粒——浅水草洞 5 粒够用，走水环境可增至 10 粒以上

## 2. 卧式漂（风漂）

### 基本信息

| 项目 | 内容 |
|------|------|
| **类型** | 卧式浮漂——椭圆/梭形横卧水面 |
| **形状/结构** | 椭圆形漂体横卧于水面，鱼吞饵拉动钓线时漂体斜立或直立，动作醒目 |
| **常见材质** | 轻木（桐木/巴尔杉）、塑料、泡沫 |
| **常见规格** | 漂体长 5~10cm，中小型为主 |
| **对象鱼种** | 鲫鱼、鲤鱼（风浪天野钓） |
| **常见品牌** | 各渔具店散装、手工自制 |
| **普遍价位** | 5~30 元 |

### 优缺点

**优点：**
- 横卧水面迎风面小，是抗风浪的经典漂型（「风漂」之名由此而来）
- 鱼讯反应方式独特（卧→立），大动作不易错过
- 结构简单价格低廉，损坏无负担

**缺点：**
- 灵敏度低于立漂和七星漂，轻口信号基本丢失
- 漂相判断滞后，多为死口后的大动作
- 现代钓法普及后市场萎缩，产品选择少

### 搭配建议

| 搭配项目 | 建议 |
|---------|------|
| **鱼线** | 传统钓线组 1.0~2.0 号 |
| **鱼竿** | 手竿 5.4~8.1m，或矶竿传统钓 |
| **最佳组合** | 7.2m 手竿 + 卧式风漂 + 活坠躺底钓组（风天野河守鲤鱼） |

### 选购建议

- **风浪天野钓**：选大一号浮力的卧式漂，配重躺底抗走水
- 现已属小众漂型，多作为传统钓情怀或特定天气补充装备
- 自制桐木卧漂成本极低，动手能力强的钓友可尝试

## 3. 立式传统漂（棒形/锥形/陀螺形漂）

### 基本信息

| 项目 | 内容 |
|------|------|
| **类型** | 立式浮漂——传统简化型 |
| **形状/结构** | 棒形、纺锤形、辣椒形、陀螺形、伞形等；一体成型无独立漂脚漂尾结构（或很短），插于漂座使用 |
| **常见材质** | 轻木（桐木/巴尔杉）、通草、塑料、高梁杆/蒲草（民间自制） |
| **常见规格** | 漂长 15~25cm |
| **对象鱼种** | 鲫鱼、鲤鱼、杂鱼（传统野钓通用） |
| **常见品牌** | 各地方渔具店散装、手工自制 |
| **普遍价位** | 3~20 元 |

### 优缺点

**优点：**
- 结构极简、价格极低，是最普及的传统漂型
- 漂体粗大视目明显，老年钓友友好
- 皮实抗造，磕碰无惧
- 调钓粗放（重坠到底钓迟钝），鱼讯以黑漂大送为主，判断简单

**缺点：**
- 灵敏度低，轻口滑口信号基本无法呈现
- 漂相单调，缺乏台钓立漂的丰富语言
- 做工普遍粗糙，同心度差影响信号传导

### 搭配建议

| 搭配项目 | 建议 |
|---------|------|
| **鱼线** | 传统线组 1.0~2.5 号 |
| **鱼竿** | 手竿 4.5~7.2m、矶竿传统钓均可 |
| **最佳组合** | 5.4m 手竿 + 棒形传统漂 + 活坠躺底（野河守鲤鱼，死口为主） |

### 选购建议

- **怀旧野钓**：散装棒形漂按斤称购，损坏无负担
- **民间自制**：高粱杆、蒜苔杆削制漂体是老一辈的智慧，趣味性强
- 若追求信号精细，建议直接升级台钓立漂（见[01 篇](/float/01)）

## 4. 羽毛梗漂（鹅毛漂）

### 基本信息

| 项目 | 内容 |
|------|------|
| **类型** | 立式浮漂——天然羽毛单梗型 |
| **形状/结构** | 取成年鹅/鸭翅膀大羽的羽梗（白色空心管），单根削制漆色即成；漂脚即羽梗本身 |
| **常见材质** | 鹅毛梗、鸭毛梗、鸡毛梗 |
| **常见规格** | 单根漂长 10~20cm |
| **对象鱼种** | 鲫鱼、小型鱼类（浅水细线） |
| **常见品牌** | 手工自制为主 |
| **普遍价位** | 2~10 元 |

### 优缺点

**优点：**
- 天然材质自重极轻、浮力适中，轻口信号柔和真实
- 制作成本低，传统钓文化符号（「鹅毛漂钓鲫鱼」是几代人的记忆）
- 空心羽梗不吸水，长期使用性能稳定
- 细线小钩配合时出口轻盈，钓慢鱼有味道

**缺点：**
- 漂体细小视距短，只适合近岸浅水
- 无精细目数刻度，观漂全凭经验
- 长度受限，深水完全不可用
- 市场几乎绝迹，需自制或淘手工

### 搭配建议

| 搭配项目 | 建议 |
|---------|------|
| **鱼线** | 细线 0.6~1.0 号 |
| **鱼竿** | 软调手竿 3.6~5.4m |
| **最佳组合** | 4.5m 软竿 + 鹅毛梗漂 + 细线小钩挂蚯蚓（近岸浅水钓小鲫，体验传统慢钓乐趣） |

### 选购建议

- 建议自制：取粗壮鹅羽梗，刮去羽枝、截取 15cm，上下漆红黑环即成
- 淘宝可搜「鹅毛浮漂」购成品，价格低廉
- 属于情怀与轻口慢钓特化装备，日常作钓仍推荐现代漂型
