# 快速开始

欢迎来到 ulnae 的个人网站！这里是一些入门指南。

## 本站介绍

本站基于 [VitePress](https://vitepress.dev) 构建，部署于 GitHub Pages。

## 如何使用

1. 浏览左侧目录了解不同分类的内容
2. 使用顶部导航快速跳转
3. 通过搜索功能查找感兴趣的内容

## 本地开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm docs:dev

# 构建生产版本
pnpm docs:build

# 预览生产构建
pnpm docs:preview
```
