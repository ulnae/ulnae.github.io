# 鱼钩规格对照表

鱼钩编号因品牌和钩型而异，以下为常见编号与尺寸的大致对照（以日本钩型标准为例）：

| 钩号  | 钩门宽度（约） | 对象鱼体型            | 典型应用         |
| --- | ------- | ---------------- | ------------ |
| 1号  | 4-5mm   | 小白条、鳑鲏           | 袖钩1号、竞之肘     |
| 2号  | 5-6mm   | 鲫鱼（50g以下）        | 袖钩2号、伊豆2号    |
| 3号  | 6-7mm   | 鲫鱼（50-150g）      | 袖钩3号、伊豆3号    |
| 4号  | 7-8mm   | 鲫鱼（150-300g）     | 袖钩4号、伊豆4号    |
| 5号  | 8-9mm   | 鲫鱼/小鲤鱼（300-500g） | 伊豆5号、关东5号    |
| 6号  | 9-10mm  | 鲤鱼/草鱼（500g-1kg）  | 伊势尼6号、伊豆6号   |
| 7号  | 10-11mm | 鲤鱼/草鱼（1-2kg）     | 伊势尼7号、千又7号   |
| 8号  | 11-13mm | 大型鲤草（2-4kg）      | 伊势尼8号、千又8号   |
| 9号  | 13-15mm | 大型鲤草/海鱼（4-8kg）   | 伊势尼9号、千又9号   |
| 10号 | 15-18mm | 超大型海鱼（8kg+）      | 伊势尼10号、千又10号 |

> **注意**：不同品牌的同号钩实际尺寸可能有差异，路亚三本钩和飞钓毛钩的编号体系与上述不同（路亚钩通常用 #2, #4, #6 等编号，数字越大钩越小）。
