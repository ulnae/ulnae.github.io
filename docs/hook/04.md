# 矶钓类鱼钩

矶钓（Rock Fishing / Ikejimi）在礁石区或防波堤进行，对象鱼多为嘴型较小但力量大的礁岩鱼类，要求钩型兼顾**隐蔽性与强度**。


## 矶奴钩

| 属性       | 详情                                        |
| -------- | ----------------------------------------- |
| **名称**   | 矶奴钩 / 矶钓钩（Iso Hook）                       |
| **使用场景** | 矶钓浮游钓法、礁岩区垂钓                              |
| **特点**   | 钩条适中，钩尖直且短，钩门窄，钩底浅圆；钩柄较长便于挂南极虾；倒刺较小；整体轻量化 |
| **对象鱼种** | 黑鲷、白毛、黑毛、黄鸡鱼、臭肚鱼等礁岩鱼类                     |
| **优点**   | 轻巧隐蔽，礁岩鱼吸食入口容易；钩柄长，挂虾方便；钩尖角度适合中小型鱼嘴       |
| **缺点**   | 强度有限，遇上大型石斑容易变形；钩门窄不适合大口型鱼                |
| **适用钓法** | 浮游矶钓、南极虾诱钓、前打钓法                           |

## 速攻钩

| 属性       | 详情                               |
| -------- | -------------------------------- |
| **名称**   | 速攻钩 / 快攻钩（Speed Hook）            |
| **使用场景** | 矶钓快速作钓、竞技矶钓                      |
| **特点**   | 钩条极细，钩尖超短，无倒刺；钩门窄，整体超轻；钩柄短       |
| **对象鱼种** | 黑毛、白毛、小型黑鲷等                      |
| **优点**   | 极轻，信号灵敏度极高；无倒刺，摘鱼速度极快；钩尖超短，刺入极迅速 |
| **缺点**   | 强度极低，大鱼必断；无倒刺容易脱钩；仅限小口型鱼         |
| **适用钓法** | 竞技矶钓、快速作钓                        |
