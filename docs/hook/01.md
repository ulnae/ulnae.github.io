# 海钓类鱼钩

海钓环境复杂多变，鱼种体型大、力量猛、牙齿锋利，同时海水具有腐蚀性。因此海钓鱼钩普遍具备**钩条粗壮、钩门宽大、抗拉力强、防锈涂层**等特征。


## 伊势尼钩

| 属性       | 详情                                             |
| -------- | ---------------------------------------------- |
| **名称**   | 伊势尼钩（Ise-Ni Hook）                              |
| **使用场景** | 海钓矶钓、远投沉底钓、船钓，也可用于淡水大鱼钓                        |
| **特点**   | 钩条粗壮，钩门较宽，钩尖内弯明显，钩尖与钩柄几乎平行，倒刺较大；钩底呈圆形弧度，整体形态宽厚 |
| **对象鱼种** | 黑鲷、真鲷、石斑、鲈鱼、鳗鱼、海鳗、黄鱼、淡水大型鲤鱼/草鱼等                |
| **优点**   | 抗拉力极强，大鱼不易拉变形；钩尖内弯角度好，中鱼后不易脱钩；通用性强，海淡皆宜        |
| **缺点**   | 钩体较重，小鱼吞食不便；钩条粗导致隐蔽性降低，警惕性高的鱼可能回避              |
| **适用钓法** | 矶钓、船钓、远投沉底钓、浮游矶钓                               |

## 千又钩

| 属性       | 详情                                          |
| -------- | ------------------------------------------- |
| **名称**   | 千又钩（Chiyo Hook）                             |
| **使用场景** | 海钓船钓、深海沉底钓、大型对象鱼垂钓                          |
| **特点**   | 钩条粗，钩尖略向外翻转（鹰嘴式），钩门宽大，钩底弧度较深；钩尖外翻设计利于挂住鱼嘴边缘 |
| **对象鱼种** | 石斑鱼、红鱼、海鳗、大型真鲷、鲷科鱼类、鲈鱼等                     |
| **优点**   | 钩尖外翻，容易刺入鱼嘴边缘，挂鱼率高；钩门宽，适合大口型海鱼；强度极高         |
| **缺点**   | 外翻钩尖容易挂底；小鱼口型不适合，容易空钩；绑线要求较高                |
| **适用钓法** | 船钓、深海沉底钓、重矶钓                                |

![千又钩等各类海钓鱼钩](/hook/01/fish_hooks_2.jpg)


## 海夕钩

| 属性       | 详情                                    |
| -------- | ------------------------------------- |
| **名称**   | 海夕钩（Kaiseki Hook）                     |
| **使用场景** | 海钓浮游钓、矶钓、近岸礁石区垂钓                      |
| **特点**   | 钩条适中偏粗，钩尖稍向内弯，钩门中等，钩底弧度流畅；钩柄较短，整体形态紧凑 |
| **对象鱼种** | 黑鲷、白毛、黑毛、黄鸡鱼、小石斑、瓜子斑等礁岩鱼类             |
| **优点**   | 隐蔽性好，不易被鱼察觉；钩尖角度适合中小型海鱼嘴型；重量适中，饵料泳姿自然 |
| **缺点**   | 强度不如伊势尼和千又，面对超大鱼可能变形；钩门偏窄，大鱼吞入不深      |
| **适用钓法** | 浮游矶钓、近岸轻矶钓、前打钓法                       |

## 串钩（葡萄钩）

| 属性       | 详情                                         |
| -------- | ------------------------------------------ |
| **名称**   | 串钩 / 葡萄钩（Gang Hook / Paternoster Rig）      |
| **使用场景** | 海钓远投、船钓多饵钓法，淡水湖泊/水库大水面垂钓                   |
| **特点**   | 由3-8枚单钩按一定间距串联绑在主线上，形如葡萄串；每枚钩可挂不同饵料，覆盖不同水层 |
| **对象鱼种** | 黄鱼、鳕鱼、海鲈、淡水鲈鱼、翘嘴、黄颡鱼等                      |
| **优点**   | 覆盖水层广，一次抛投可同时钓多个水深的鱼；可挂多种饵料，提高命中率；适合搜索型钓法  |
| **缺点**   | 挂底概率高（钩多）；收线容易缠绕；远投阻力大；摘鱼麻烦                |
| **适用钓法** | 远投沉底钓、船钓、湖泊水库搜索钓                           |

![串钩/葡萄钩（Gang Hook / Paternoster Rig）](/hook/01/chain_hook.jpg)

## 爆炸钩（炸弹钩）

| 属性       | 详情                                           |
| -------- | -------------------------------------------- |
| **名称**   | 爆炸钩 / 炸弹钩（Bomb Hook / Feeder Rig）            |
| **使用场景** | 海钓远投饵料团钓法，淡水湖泊/水库大水面群钓                       |
| **特点**   | 由6-8枚钩集中绑在一个连接环上，饵料捏成团包裹钩组，抛投入水后饵料散开，钩暴露在饵料中 |
| **对象鱼种** | 鲤鱼、鲫鱼、草鱼、鳊鱼、黄鱼、海鲫鱼等群居性鱼类                     |
| **优点**   | 诱钓结合，饵料散开后钩暴露其中，鱼吸食即中钩；可同时挂多条鱼；适合大水面群钓       |
| **缺点**   | 饵料团制作需要技巧；抛投要求高，散落时机不好控制；收线缠绕严重；挂底率高         |
| **适用钓法** | 远投沉底钓、饵料团钓法、湖泊水库大水面钓                         |

![爆炸钩/炸弹钩（Bomb Hook / Feeder Rig）](/hook/01/bomb_hook.jpg)

## 章鱼针（鱿鱼钩）

| 属性       | 详情                                                         |
| -------- | ---------------------------------------------------------- |
| **名称**   | 章鱼针 / 鱿鱼钩 / 木虾钩（Egi / Squid Jig）                           |
| **使用场景** | 海钓岸抛或船钓鱿鱼、章鱼、乌贼等头足类                                        |
| **特点**   | 非传统鱼钩形态，为一枚带铅头的仿虾形拟饵，底部镶嵌两排朝上的伞状倒钩（无倒刺），通过跳底抽动模拟虾类逃窜诱使鱿鱼抱饵 |
| **对象鱼种** | 鱿鱼（枪乌贼）、章鱼、墨鱼、乌贼等头足类                                       |
| **优点**   | 专门针对头足类设计，鱿鱼抱饵后伞钩自动挂住触手；无需挂真饵，使用方便；铅头可调整沉降速度               |
| **缺点**   | 需要一定操作技巧（抽竿节奏）；挂底概率极高；不同水深需要不同克重；价格较高                      |
| **适用钓法** | 矶抛钓（Eging）、船钓鱿鱼                                            |
