# 筏钓类鱼钩

筏钓（Raft Fishing）在养殖筏、排筏等水域垂钓，对象鱼多为中小型鱼，注重**轻量化和入口性**。


### 筏钓小钩

![筏钓钩](/hook/fune-hook.png)

| 属性       | 详情                                           |
| -------- | -------------------------------------------- |
| **名称**   | 筏钓钩 / 筏小钩（Fune Hook / Sabiki Hook）           |
| **使用场景** | 养殖筏区、排筏区垂钓小型鱼类                               |
| **特点**   | 钩条极细，钩尖短直，钩门窄，钩底浅圆；钩柄短；常以多枚串绑成 Sabiki 串钩形式使用 |
| **对象鱼种** | 黄鸡鱼、黑毛、白毛、沙梭、瓜子鲷等小型鱼                         |
| **优点**   | 极轻，小型鱼吸食入口容易；可多枚串绑覆盖多水层；灵敏度极高                |
| **缺点**   | 强度极低，稍大鱼即变形；钩门窄，仅限小鱼嘴型                       |
| **适用钓法** | 筏钓、Sabiki串钓、养殖筏区垂钓                           |
