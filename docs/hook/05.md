# 飞钓类鱼钩

飞钓（Fly Fishing）使用毛钩（人工绑制的拟饵）模拟昆虫或水生生物，鱼钩本身需被绑制材料包裹。飞钓钩注重**钩条纤细、钩尖角度精确、防锈**。


## 毛钩（飞蝇钩）

| 属性       | 详情                                                    |
| -------- | ----------------------------------------------------- |
| **名称**   | 毛钩 / 飞蝇钩（Fly Hook）                                    |
| **使用场景** | 飞钓（Fly Fishing）全场景，溪流、湖泊、海钓飞蝇均可                       |
| **特点**   | 钩条细，钩尖直或略弯（取决于毛钩类型），钩门窄；钩柄长度和形态因绑制需求而异；通常为不锈钢或高碳钢防锈处理 |
| **对象鱼种** | 鳟鱼、虹鳟、褐鳟、溪哥、马口鱼、石斑（海飞蝇）等                              |
| **优点**   | 配合绑制材料可实现极高仿真度；轻量化，浮水/沉水均可；钩尖精细，刺入迅速                  |
| **缺点**   | 需配合飞钓竿线系统使用（技术门槛高）；钩条细，大鱼容易拉变形；绑制毛钩需要额外技能             |
| **适用钓法** | 飞钓（Fly Fishing）全系列                                    |

## 干式毛钩

| 属性       | 详情                                        |
| -------- | ----------------------------------------- |
| **名称**   | 干式毛钩钩（Dry Fly Hook）                       |
| **使用场景** | 水面浮水飞钓，模拟水面昆虫                             |
| **特点**   | 钩条极细，钩尖向上微弯（防止挂水草），钩门窄；钩柄短，以便绑制材料覆盖钩体保持浮力 |
| **对象鱼种** | 鳟鱼、溪哥、马口鱼等水面摄食鱼类                          |
| **优点**   | 极轻盈，配合浮水毛绑材料可在水面漂浮；钩尖向上微弯减少挂底             |
| **缺点**   | 极细钩条，强度极低；仅限小鱼；水面操作需精准抛投                  |
| **适用钓法** | 干式飞钓（Dry Fly Fishing）                     |

## 若虫/湿式毛钩

| 属性       | 详情                                                      |
| -------- | ------------------------------------------------------- |
| **名称**   | 若虫/湿式毛钩钩（Nymph / Wet Fly Hook）                          |
| **使用场景** | 水下沉水飞钓，模拟水生昆虫幼虫或若虫                                      |
| **特点**   | 钩条比干式毛钩粗，钩尖直且略长，钩门中等；钩柄中等或偏长，便于绑制若虫形态材料；通常为重水钩（sinking） |
| **对象鱼种** | 鳟鱼、虹鳟、褐鳟、溪哥等底层/中层摄食鱼类                                   |
| **优点**   | 钩条较粗，强度优于干式毛钩；模拟水生幼虫形态逼真；可下沉至鱼所在水层                      |
| **缺点**   | 需配合沉水飞蝇线使用；水下信号传递不如路亚直接                                 |
| **适用钓法** | 若虫飞钓（Nymphing）、湿式飞钓（Wet Fly）                            |
