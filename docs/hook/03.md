# 路亚钓类鱼钩

路亚钓（Lure Fishing）以拟饵模拟猎物引诱掠食性鱼类攻击，鱼钩需配合拟饵使用。路亚钩注重**穿透力、抗变形、防挂底**，同时钩尖角度需匹配拟饵泳姿。


### 三本钩（三锚钩）

![三本钩](/hook/treble-hook.png)

| 属性       | 详情                                              |
| -------- | ----------------------------------------------- |
| **名称**   | 三本钩 / 三锚钩（Treble Hook）                          |
| **使用场景** | 路亚硬饵（米诺、波趴、VIB、铁板等）标配钩组                         |
| **特点**   | 三个钩尖呈120度均布于连接环上，形成三方向覆盖；钩条粗细有多种规格，钩尖锋利带倒刺      |
| **对象鱼种** | 鲈鱼、翘嘴、鳜鱼、狗鱼、海鲈、GT（牛港）、金枪鱼、鲅鱼等掠食性鱼类              |
| **优点**   | 三方向覆盖，中鱼率极高；适合各种硬饵拟饵；钩尖多，鱼挣扎时总有一个方向钩住           |
| **缺点**   | 挂底概率极高（三方向都可能挂）；摘钩困难，尤其深喉时；容易伤鱼，不便于放流；对操作者有安全隐患 |
| **适用钓法** | 路亚硬饵钓法（米诺/波趴/VIB/铁板等）                           |

### 曲柄钩（曲轴钩）

![曲柄钩](/hook/offset-hook.png)

| 属性       | 详情                                            |
| -------- | --------------------------------------------- |
| **名称**   | 曲柄钩 / 曲轴钩 / 软饵钩（Offset Hook / Worm Hook）      |
| **使用场景** | 路亚软饵钓法（德州钓组、Wacky钓组等）                         |
| **特点**   | 钩柄在钩尖入口处有一个Z形弯折（偏轴设计），使软饵可隐藏钩尖实现防挂底；钩门宽大，钩尖锋利 |
| **对象鱼种** | 鲈鱼（大口鲈/小口鲈）、鳜鱼、黑鱼、翘嘴、雷鱼等                      |
| **优点**   | Z形弯折使钩尖可藏于软饵中，穿越障碍区不挂底；钩门宽大，大口鱼容易吞入；穿透力强      |
| **缺点**   | 需配合软饵使用，不能单独使用；穿饵技巧有门槛；钩尖隐藏导致刺鱼时需多抽一段距离       |
| **适用钓法** | 德州钓组（Texas Rig）、Wacky钓组、Neko钓组、水面软饵           |

### 铅头钩

![铅头钩](/hook/jig-head-hook.png)

| 属性       | 详情                                           |
| -------- | -------------------------------------------- |
| **名称**   | 铅头钩（Jig Head）                                |
| **使用场景** | 路亚软饵钓法，需控制沉降速度和水层                            |
| **特点**   | 钩柄前端铸有铅制圆球形/鱼形/箭形配重头，一体成型；铅头自带配重和泳姿辅助设计，钩尖外露 |
| **对象鱼种** | 鲈鱼、翘嘴、海鲈、鳜鱼、沙梭、黄鸡鱼等                          |
| **优点**   | 配重与钩一体，抛投精准；铅头形状影响泳姿，可精细操控；不同克重适应不同水深/水流     |
| **缺点**   | 铅头外露，挂底概率高（尤其礁石区）；钩尖外露不如曲柄钩隐蔽；需更换不同克重适应不同钓场  |
| **适用钓法** | 软饵铅头钓组、近岸路亚、底层搜索路亚                           |

### 路亚单钩

![路亚单钩](/hook/single-hook.png)

| 属性       | 详情                                        |
| -------- | ----------------------------------------- |
| **名称**   | 路亚单钩（Single Hook / Replacement Hook）      |
| **使用场景** | 替换硬饵原装三本钩，减少挂底或用于放流钓法                     |
| **特点**   | 钩条粗壮，钩门宽大，钩尖内弯明显，钩底深圆；通常带有大号连接环；无倒刺版本用于放流 |
| **对象鱼种** | 鲈鱼、海鲈、GT、金枪鱼、三文鱼等大型掠食鱼                    |
| **优点**   | 单钩挂底概率大幅降低；摘鱼速度快；对鱼伤害小，适合放流；大鱼作钓安全性好      |
| **缺点**   | 中鱼率不如三本钩（仅一个方向）；需鱼吞入较深才能钩住；不适合短口型鱼        |
| **适用钓法** | 路亚硬饵替换单钩、飞蝇辅助、放流路亚                        |

### 内置铅曲柄钩

![内置铅曲柄钩](/hook/weighted-offset-hook.png)

| 属性       | 详情                                            |
| -------- | --------------------------------------------- |
| **名称**   | 内置铅曲柄钩（Weighted Offset Hook /内铅曲柄钩）           |
| **使用场景** | 软饵钓法需要配重但不想外露铅头的场景                            |
| **特点**   | 在曲柄钩的钩柄内部嵌入铅块配重，外观看不到铅头；兼具曲柄钩防挂底特性和铅头钩的配重沉降功能 |
| **对象鱼种** | 鲈鱼、鳜鱼、翘嘴等                                     |
| **优点**   | 配重内置不外露，防挂底性优于铅头钩；保持了曲柄钩的隐蔽性；泳姿自然             |
| **缺点**   | 配重固定不可更换；克重选择有限；价格高于普通曲柄钩                     |
| **适用钓法** | 德州钓组改良版、精细软饵钓法、底层搜索                           |
