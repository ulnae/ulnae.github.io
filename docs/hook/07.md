# 特殊用途鱼钩


## 有刺/无刺倒钩对比

| 对比项      | 有倒刺钩         | 无倒刺钩             |
| -------- | ------------ | ---------------- |
| **防脱钩**  | 优秀，倒刺卡住鱼嘴不易脱 | 差，需始终绷紧竿线        |
| **摘鱼速度** | 慢，需用力拔出      | 极快，一推即脱          |
| **对鱼伤害** | 大，取出时撕裂鱼嘴    | 小，适合放流           |
| **适用场景** | 休闲野钓、海钓大鱼    | 竞技比赛、放流钓法、路亚C\&R |
| **安全**   | 钩住人手时取出困难    | 钩住人手时容易取出        |

## 拟饵内置钩

| 属性       | 详情                                      |
| -------- | --------------------------------------- |
| **名称**   | 拟饵内置钩 / 内藏钩（Inline / Through-Wire Hook） |
| **使用场景** | 软饵路亚、管饵钓法                               |
| **特点**   | 钩尖完全隐藏于软饵管体内，仅钩尖略露；设计上使鱼咬饵时钩尖才暴露        |
| **对象鱼种** | 鲈鱼、鳜鱼、海鲈、狗鱼等                            |
| **优点**   | 几乎零挂底（钩尖隐藏）；泳姿自然；对鱼伤害小                  |
| **缺点**   | 需要鱼吞入较深才能刺钩；穿饵技巧要求高；仅限软饵使用              |
| **适用钓法** | 管饵钓法（Tube）、软饵内藏钓法                       |

## 卡钩（搭钩）

| 属性       | 详情                                     |
| -------- | -------------------------------------- |
| **名称**   | 卡钩 / 搭钩 / 抄钩（Gaff Hook）                |
| **使用场景** | 海钓大型鱼上船后的辅助工具，非垂钓钩                     |
| **特点**   | 无倒刺或有大倒刺的大型钩，安装在长杆上；钩门极宽，钩尖锋利；用于直接拉鱼上船 |
| **对象鱼种** | 大型海鱼（金枪鱼、GT、石斑、鲨鱼等）                    |
| **优点**   | 快速将大鱼拉上船，防止鱼挣脱跑线                       |
| **缺点**   | 对鱼伤害大，不适合放流；操作不当易伤人                    |
| **适用钓法** | 船钓辅助工具（非垂钓用钩）                          |
