## 常见鱼钩材质说明

| 材质              | 特点            | 适用场景      |
| --------------- | ------------- | --------- |
| **高碳钢**         | 硬度高、锋利，但易生锈   | 淡水钓通用     |
| **不锈钢**         | 防锈耐腐蚀，但硬度略低   | 海钓、矶钓     |
| **高碳钢镀镍/钛**     | 兼顾硬度与防锈       | 高端鱼钩通用    |
| **化学涂层（PTFE等）** | 超滑涂层，穿透力极强    | 竞技钓、高端路亚钩 |
| **钛合金**         | 超轻、超强、防锈，价格极高 | 顶级竞技/飞钓   |
