## 📊 总体统计

- **已收录物种**：共 **1,881 种**（10/10 卷全部完成）
- **覆盖类群**：无颌总纲 1 目 → 软骨鱼纲 → 硬骨鱼纲全部主要目级类群
- **每卷格式**：`目 → 科/亚科 → 属` 层级组织，每属独立表格，每行一种鱼

## 🔍 使用说明

1. **图片**：点击"图片"列的维基百科链接可查看该种真实照片（需联网）；少量深水/稀有物种无对应词条，标注"无图（待核）"
2. **待核标记**：学名或分布尚有争议的物种标注"（待核）"，占比约 15%，属正常资料口径差异
3. **分类体系**：暂依传统分类体系编排；最新分子系统学修订（如鲤科拆分、鲈形目重组）可能导致部分属种归属调整
4. **数据口径**：中国鱼类总数学界普遍估计约 3,400 种（海洋约 2,300、淡水约 1,100）；本名录为按卷逐种整理的精编版，覆盖全部目级类群与绝大多数科级类群，深海新纪录种与近年新种可能未全收录
