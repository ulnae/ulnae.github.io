# 筏钓及特殊钓法鱼竿详解

> **使用场景**：本文档覆盖三类特殊玩法钓竿——**筏钓竿**（鱼排/网箱/船筏垂直钓）、**前打竿**（海岸礁石垂直钓）、**中通竿**（线走竿内的高端泛用竿）。它们共同特点是：针对特定场景的精细作钓，对灵敏度要求极高。

## 1. 筏钓竿（筏竿）

### 基本信息
| 项目 | 内容 |
|------|------|
| **材质** | 碳纤维（中高吨位）、玻碳混合（入门款） |
| **特点** | 竿身短小（1.2~1.8m），配小导环 + 筏钓专用轮（或小型纺车轮）；竿梢极软（部分配"荧光竿梢"便于夜钓观察），垂直钓法，铅坠落底后看竿梢信号；常见"双梢/三梢"设计（不同硬度竿梢互换） |
| **常见尺寸** | 1.2m / 1.5m / 1.8m / 2.1m（1.5m 最常用） |
| **自重范围** | 50~150g |
| **钓重（顶钓）** | 300g~1500g（竿梢号数决定灵敏度与钓力） |
| **对象鱼种** | 翘嘴、鳜鱼、黄尾鲴、红尾、鲤鱼、草鱼（淡水网箱/鱼排）；也可用于海水排钓（黑鲷） |
| **常见品牌** | 光威、汉鼎、迪佳（Daiwa）、禧玛诺（Shimano）、东区筏钓、化氏 |
| **普遍价位** | 50~800 元；入门 50~120 元，国产主流 150~400 元，日系 500 元起 |

### 优缺点
**优点：**
- 竿梢灵敏度极高，铅坠触底、鱼啄饵的每个细节都清晰可见
- 竿短轻便，网箱、鱼排、船筏等狭窄环境操作灵活
- 双梢/三梢设计一套竿可切换不同鱼情
- 装备轻量化，夜钓（荧光梢）体验好

**缺点：**
- 只能垂直作钓，场景局限于排筏、网箱、桥筏
- 竿短导致搏鱼空间小，中大鱼后遛鱼困难，易切线
- 竿梢脆弱，挂底、大力扬竿容易损坏
- 需要配套筏钓轮（带缓降功能）才能发挥全部性能

### 选购建议
- **入门**：1.5m 双梢筏竿（100~200 元）+ 筏钓轮，网箱钓翘嘴
- **桥筏**：选 1.5~1.8m，配缓降轮，夜钓黄尾、鳜鱼


## 2. 前打竿

### 基本信息
| 项目 | 内容 |
|------|------|
| **材质** | 高碳纤维（40T~60T），导环为小口径密集设计（前打环） |
| **特点** | 外形似矶钓竿但更细更轻，线从竿体外部小导环穿过（"前打"指线在前端出线）；极轻量竿梢，配前打轮（小型鼓轮）或纺车轮；主打海岸礁石、防波堤垂直落饵钓法，饵料（活虾/小活鱼）随水流漂入礁缝 |
| **常见尺寸** | 3.6m / 4.2m / 4.5m / 5.0m / 5.4m（4.5m 最常用） |
| **自重范围** | 100~200g（比同长度矶钓竿轻 30% 左右） |
| **钓重（顶钓）** | 500g~1800g（按号数，常见 0.6号~1.5号） |
| **对象鱼种** | 黑鲷、黄鳍鲷、石斑、沙尖鱼、海鲈（海水礁区） |
| **常见品牌** | 伽玛卡兹（Gamakatsu）、达瓦（Daiwa）、禧玛诺（Shimano）、黑鲷工房、光威 |
| **普遍价位** | 200~3000 元；国产入门 200~500 元，日系中端 800~1800 元，高端（伽玛卡兹）2500 元起 |

### 优缺点
**优点：**
- 手感细腻至极，微小的咬口信号都能传递到手
- 竿身轻，单手持竿控线轻松，适合长时间"逗钓"
- 前打钓法可精准控制活饵下沉深度，礁缝猎大鲷效率极高
- 铅坠轻（0.5~1.5g），几乎无落水噪音，不惊鱼

**缺点：**
- 钓法进阶难度高（控线、逗饵、抓口全靠手感经验）
- 只适合礁石/防波堤垂直作钓，开阔水域不适用
- 细竿梢极脆弱，浪涌中操作不当易断
- 前打轮价格不菲，整套装备投入偏高

### 选购建议
- **新手**：4.5m 1号前打竿（国产 300~500 元），配前打轮，防波堤练手感
- **进阶**：0.8号日系前打竿，轻量化与灵敏度优先


## 3. 中通竿（穿线竿）

### 基本信息
| 项目 | 内容 |
|------|------|
| **材质** | 高碳纤维（竿壁空心设计，内部走线通道），高端含高模量碳布 |
| **特点** | 钓线从轮座处穿入**竿体内部**、从竿梢出线，外部无导环（或仅竿梢一个环）；彻底解决"风线缠绕竿梢/导环"问题，顺风逆风抛投都顺畅；外观简洁一体，泛用性强 |
| **常见尺寸** | 3.6m / 4.5m / 5.4m / 6.3m（4.5m、5.4m 最常用） |
| **自重范围** | 110~220g |
| **钓重（顶钓）** | 800g~2500g |
| **对象鱼种** | 鲫鱼、鲤鱼、草鱼（淡水）；黑鲷、真鲷（海水矶岸） |
| **常见品牌** | 达瓦（Daiwa）、禧玛诺（Shimano）、伽玛卡兹（Gamakatsu）、光威、汉鼎 |
| **普遍价位** | 200~2500 元；国产入门 200~400 元，日系中端 800~1500 元，高端 2000 元起 |

### 优缺点
**优点：**
- 无外导环缠绕问题，抛投顺畅度极佳，尤其适合有风天气
- 外观简洁、收纳方便，不必担心导环磕碰
- 主线全部藏于竿内，钓线磨损小，耐用度高
- 兼顾淡水/海水多种玩法，泛用性强

**缺点：**
- 竿内走线通道增加重量，同规格比外导环竿略重
- 换线、挂底断线后穿线麻烦（需专用穿线针/钢丝）
- 竿内进水后不易干燥，长期使用需注意保养
- 中鱼后线在竿内弯曲处摩擦力大于外导环，抛投轻饵略吃亏

### 选购建议
- 风大水域、频繁抛投场景首选中通竿
- 新手建议 4.5m 中通竿（300 元左右），注意购买时确认附赠穿线器


## 筏钓/前打/中通竿选型速查表

| 竿型 | 最佳场景 | 常见长度 | 配轮类型 | 钓重 | 价位区间 | 首选人群 |
|------|----------|----------|----------|------|----------|----------|
| 筏钓竿 | 网箱/鱼排/桥筏 | 1.2~2.1m | 筏钓轮/纺车 | 300~1500g | 50~800元 | 排筏钓友 |
| 前打竿 | 海岸礁石垂直钓 | 3.6~5.4m | 前打轮/纺车 | 500~1800g | 200~3000元 | 手感发烧友 |
| 中通竿 | 大风天气泛用 | 3.6~6.3m | 纺车/鼓轮 | 800~2500g | 200~2500元 | 泛用/风天作钓 |

> **温馨提示**：中通竿保养重点是定期检查竿内走线通道并通风干燥；前打竿与筏钓竿的细竿梢是易损件，购买时可多备一根同型号竿梢。
